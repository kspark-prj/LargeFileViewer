## 1. NSIS 다운로드 및 설치

1. **공식 사이트 접속**
* [NSIS 공식 웹사이트(SourceForge)](https://nsis.sourceforge.io/Download)에 접속합니다.


2. **설치 파일 다운로드**
* **Download** 버튼을 눌러 최신 버전의 설치 파일(예: `nsis-x.xx-setup.exe`)을 다운로드합니다.


3. **설치 진행**
* 다운로드한 파일을 실행합니다.
* 기본 옵션(Full 설치) 그대로 **[Next]** 및 [Install]을 진행하여 설치를 완료합니다.
* 기본 설치 경로는 `C:\Program Files (x86)\NSIS` 입니다.

---

## 3. 스크립트 빌드 방법 (3가지)

NSIS 스크립트(`.nsi`)를 설치 파일(`.exe`)로 변환하는 방법은 다음과 같습니다.

### 방법 1: GUI 메인 메뉴 활용

1. **NSIS** 시작 메뉴 프로그램을 실행합니다.
2. **[Compile NSI scripts]** 메뉴를 클릭합니다.
3. `.nsi` 파일을 드래그 앤 드롭(Drag & Drop)하면 자동으로 컴파일되어 설치 파일이 생성됩니다.

### 방법 2: 우클릭 마우스 컨텍스트 메뉴 활용

* 작성해 둔 `.nsi` 스크립트 파일에서 **마우스 우클릭** → [Compile NSIS Script]를 선택합니다.

### 방법 3: CLI / 배치 파일(`build.bat`) 활용

* 앞서 공유해 드린 `build.bat` 배치 파일처럼 명령 프롬프트(CMD) 환경에서 실행할 수도 있습니다.
```cmd
"C:\Program Files (x86)\NSIS\makensis.exe" setup.nsi

```



## 1. NSIS 설치 스크립트 (`setup.nsi`)

프로그램 파일 복사, 컨텍스트 메뉴 레지스트리 등록, 그리고 제거(Uninstall) 기능까지 포함된 스크립트입니다. 스크립트 파일과 같은 폴더에 `Hawkeye.exe` 및 `app.ico` 파일이 있다고 가정합니다.

```nsis
!define PRODUCT_NAME "Hawkeye"
!define PRODUCT_VERSION "1.0.0"
!define PRODUCT_PUBLISHER "Hawkeye Studio"
!define EXE_NAME "Hawkeye.exe"
!define ICON_FILE "main.ico" ; 아이콘 파일명

; Modern UI 적용
!include "MUI2.nsh"

Name "${PRODUCT_NAME} ${PRODUCT_VERSION}"
OutFile "HawkeyeSetup.exe"
InstallDir "$PROGRAMFILES64\${PRODUCT_NAME}"
RequestExecutionLevel admin ; 레지스트리 등록을 위한 관리자 권한 요청

; 설치/언인설러 아이콘 지정
!define MUI_ICON "${ICON_FILE}"
!define MUI_UNICON "${ICON_FILE}"

; 페이지 설정
!insertmacro MUI_PAGE_DIRECTORY
!insertmacro MUI_PAGE_INSTFILES
!insertmacro MUI_UNPAGE_CONFIRM
!insertmacro MUI_UNPAGE_INSTFILES

; 언어 설정
!insertmacro MUI_LANGUAGE "Korean"

; 설치 섹션
Section "MainSection" SEC01
    SetOutPath "$INSTDIR"
    
    ; 설치할 파일 복사 (스크립트 경로에 Hawkeye.exe가 존재해야 함)
    File "${EXE_NAME}"
    
    ; 1. 컨텍스트 메뉴 레지스트리 등록
    WriteRegStr HKCR "*\shell\HawkeyeViewer" "" "Hawkeye로 열기"
    WriteRegStr HKCR "*\shell\HawkeyeViewer" "Icon" "$INSTDIR\${EXE_NAME}"
    WriteRegStr HKCR "*\shell\HawkeyeViewer\command" "" '"$INSTDIR\${EXE_NAME}" "%1"'

    ; 2. 제어판 프로그램 추가/제거 등록
    WriteRegStr HKLM "Software\Microsoft\Windows\CurrentVersion\Uninstall\${PRODUCT_NAME}" "DisplayName" "${PRODUCT_NAME}"
    WriteRegStr HKLM "Software\Microsoft\Windows\CurrentVersion\Uninstall\${PRODUCT_NAME}" "UninstallString" "$INSTDIR\Uninstall.exe"
    WriteRegStr HKLM "Software\Microsoft\Windows\CurrentVersion\Uninstall\${PRODUCT_NAME}" "DisplayIcon" "$INSTDIR\${EXE_NAME}"
    WriteRegStr HKLM "Software\Microsoft\Windows\CurrentVersion\Uninstall\${PRODUCT_NAME}" "Publisher" "${PRODUCT_PUBLISHER}"
    WriteRegStr HKLM "Software\Microsoft\Windows\CurrentVersion\Uninstall\${PRODUCT_NAME}" "DisplayVersion" "${PRODUCT_VERSION}"
    
    ; 언인설러 생성
    WriteUninstaller "$INSTDIR\Uninstall.exe"
SectionEnd

; 제거 섹션
Section "Uninstall"
    ; 1. 파일 삭제
    Delete "$INSTDIR\${EXE_NAME}"
    Delete "$INSTDIR\Uninstall.exe"
    RMDir "$INSTDIR"

    ; 2. 컨텍스트 메뉴 레지스트리 삭제
    DeleteRegKey HKCR "*\shell\HawkeyeViewer"

    ; 3. 제어판 등록 정보 삭제
    DeleteRegKey HKLM "Software\Microsoft\Windows\CurrentVersion\Uninstall\${PRODUCT_NAME}"
SectionEnd

```

## 2. 자동 빌드 스크립트 (`build.bat`)

NSIS가 기본 설치 경로(`C:\Program Files (x86)\NSIS\makensis.exe`)에 설치되어 있을 때 명령 프롬프트에서 즉시 빌드해 주는 배치 파일입니다.

```bat
@echo off
chcp 65001 > nul
echo =========================================
echo  Hawkeye Installer 빌드를 시작합니다...
echo =========================================

:: NSIS 실행 파일 경로 설정
set MAKENSIS="C:\Program Files (x86)\NSIS\makensis.exe"

:: NSIS 설치 여부 확인
if not exist %MAKENSIS% (
    echo [ERROR] NSIS가 설치되어 있지 않거나 경로를 찾을 수 없습니다.
    echo C:\Program Files (x86)\NSIS\makensis.exe 경로를 확인해 주세요.
    pause
    exit /b
)

:: NSI 스크립트 컴파일 실행
%MAKENSIS% /V3 "setup.nsi"

if %ERRORLEVEL% EQU 0 (
    echo.
    echo =========================================
    echo  빌드가 성공적으로 완료되었습니다!
    echo  결과물: HawkeyeSetup.exe
    echo =========================================
) else (
    echo.
    echo [ERROR] 빌드 중 오류가 발생했습니다.
)

pause

```

## 3. 사전 준비 및 사용 방법

> [!NOTE]
> 배치 파일을 실행하기 전에 작업 폴더를 아래 구조와 같이 맞춰주세요.

1. **폴더 구조 준비**
* `setup.nsi` (위의 NSIS 스크립트)
* `build.bat` (위의 배치 파일)
* `Hawkeye.exe` (실제 실행 파일)
* `main.ico` (아이콘 이미지 파일)


2. **빌드 실행**
* `build.bat` 파일을 두 번 클릭하여 실행하면, 동일한 폴더에 **`HawkeyeSetup.exe`** 설치 파일이 생성됩니다.
